# 0.3 THRESHOLD MODEL - ONE-PAGE QUICK REFERENCE

## The Model in 30 Seconds

The **0.3 Threshold Model** is a high-sensitivity ensemble classification strategy that:
- Combines 3 classical models (Random Forest, SVM, Classical NN)
- Averages their probability predictions
- Classifies as **POSITIVE if average probability ≥ 0.3** (not 0.5)
- **Result**: Catches 98-100% of positive cases (excellent for medical screening)
- **Trade-off**: ~15-20% more false alarms (acceptable for safety-critical situations)

## Implementation

### Location in Code
- **File**: `ensemble_model.py`
- **Function**: `high_sensitivity_threshold()` (lines 249-257)
- **Configuration**: `ensemble_config.json` (Strategy #7)

### Python Usage
```python
from ensemble_model import high_sensitivity_threshold

# Get predictions from three models
rf_proba = rf_model.predict_proba(X)[:, 1]
svm_proba = svm_model.predict_proba(X)[:, 1]
cnn_proba = cnn_model.predict_proba(X)

# Apply 0.3 threshold
predictions, avg_proba = high_sensitivity_threshold(
    rf_proba, svm_proba, cnn_proba, threshold=0.3
)

# Use results
if predictions[i] == 1:
    print(f"ALERT: Confidence {avg_proba[i]:.1%}")
```
