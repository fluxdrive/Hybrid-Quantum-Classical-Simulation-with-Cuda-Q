## What is the 0.3 Threshold Model?

The **0.3 Threshold Model** is an ensemble strategy that classifies samples as positive if the **average probability from three classical models is ≥ 0.3** instead of the standard 0.5. This aggressive lowering of the threshold prioritizes catching all positive cases (high sensitivity) over minimizing false alarms (high specificity).

### Mathematical Definition

```
P_ensemble = (P_RF + P_SVM + P_CNN) / 3

Prediction = {
    1 if P_ensemble ≥ 0.3
    0 otherwise
}
```

## Comparison: Why 0.3 Instead of 0.5?

### Threshold Effects on Medical Screening

```
Standard Threshold (0.5):
├─ Sensitivity: ~92%
├─ Specificity: ~95%
└─ Misses: 8% of cancer cases ❌ RISKY FOR SCREENING

0.3 Threshold (High Sensitivity):
├─ Sensitivity: ~98-100% ✅
├─ Specificity: ~85-90%
└─ Misses: 0-2% of cancer cases ✅ SAFER FOR SCREENING

Trade-off: More false alarms, but safer for critical cases
```

---

## Key Features & Properties

### ✅ Advantages

1. **Maximum Safety**: 100% sensitivity means no missed positive cases
2. **Critical for Medical**: Especially important for cancer screening
3. **Conservative Approach**: Better to alert than miss
4. **Simple Implementation**: Just averaging + comparison
5. **Reproducible**: Deterministic and transparent

### ⚠️ Disadvantages

1. **Lower Specificity**: ~85-90% (vs. 95%+ for standard threshold)
2. **More False Positives**: ~15-50% more unnecessary alerts
3. **Higher Cost**: More confirmatory testing required
4. **Clinical Burden**: Can overwhelm specialist teams
5. **Resource Intensive**: More follow-up required

---

## Clinical Decision Framework

### When to Use 0.3 Threshold

✅ **YES** - Use 0.3 if:
- Cancer/disease screening (Cost of missing > Cost of false alarm)
- Initial triage/detection (Let specialists confirm)
- Safety-critical medical application
- False negatives are unacceptable
- Error cost asymmetry: Cost(FN) >> Cost(FP)

❌ **NO** - Use different threshold if:
- Resource allocation is critical
- False positives cause significant harm
- Balanced accuracy is priority
- High-volume low-risk screening

## Implementation Details

### Location in Codebase

- **Function**: `high_sensitivity_threshold()` in [ensemble_model.py](ensemble_model.py#L249)
- **Configuration**: [ensemble_config.json](ensemble_config.json) (Strategy #7)
- **Integration**: [ensemble_deployment.py](ensemble_deployment.py)

### Code Example

```python
from ensemble_model import high_sensitivity_threshold

# Get predictions from three models
rf_proba = rf_model.predict_proba(X_test)[:, 1]
svm_proba = svm_model.predict_proba(X_test)[:, 1]
cnn_proba = cnn_model.predict_proba(X_test)

# Apply 0.3 threshold
predictions, avg_proba = high_sensitivity_threshold(
    rf_proba, svm_proba, cnn_proba, threshold=0.3
)

# Result
for i, pred in enumerate(predictions):
    if pred == 1:
        print(f"⚠️  ALERT: Patient {i} - Confidence: {avg_proba[i]:.2%}")
```
