## 3. Error Type Analysis

### False Positives vs False Negatives

```
COST ASYMMETRY IN MEDICAL SCREENING:
──────────────────────────────────────

False Negative (Missed Cancer):
  ├─ Immediate Cost: $0 (no action)
  ├─ Long-term Cost: $500,000 - $2,000,000
  │  (late-stage treatment, lost productivity)
  ├─ Human Cost: Life-threatening delay
  └─ Total: UNACCEPTABLE ❌

False Positive (Unnecessary Alert):
  ├─ Immediate Cost: $500 - $2,000 (confirmatory tests)
  ├─ Patient Cost: Temporary anxiety
  ├─ Resolution: Simple confirmation (usually negative)
  └─ Total: ACCEPTABLE ✓

CONCLUSION: Cost(FN) >>> Cost(FP)
            → Prioritize sensitivity
```

## 7. Failure Mode Analysis

### Potential Failure Scenarios

```
SCENARIO 1: High False Positive Volume
───────────────────────────────────────
Cause:     Model uncertainty increases
Symptom:   >50% of alerts are false positives
Impact:    Overwhelmed clinical team
Mitigation:
  → Increase threshold to 0.35
  → Add model confidence filtering
  → Implement alert batching

SCENARIO 2: Sensitivity Drop
──────────────────────────────
Cause:     Model drift or data distribution change
Symptom:   False negative rate > 5%
Impact:    Missed cancer cases (CRITICAL)
Mitigation:
  → Retrain component models immediately
  → Investigate data drift
  → Lower threshold if needed
  → Alert clinical leadership

SCENARIO 3: Model Calibration Issues
─────────────────────────────────────
Cause:     Probabilities don't match true likelihood
Symptom:   Predicted probability ≠ actual accuracy
Impact:    Threshold become meaningless
Mitigation:
  → Recalibrate models using calibration techniques
  → Use Platt scaling or isotonic regression
  → Verify with holdout test set

SCENARIO 4: Class Imbalance Shift
──────────────────────────────────
Cause:     Real-world cancer prevalence differs from training
Symptom:   Metrics change when deployed
Impact:    Performance mismatch
Mitigation:
  → Adjust threshold dynamically
  → Use stratified sampling in retraining
  → Monitor prevalence metrics
```
